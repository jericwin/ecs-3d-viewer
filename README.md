# ECS Learning Device – 3D Viewer

Interactive, measurable 3D model of the **Development of a Body Management and Underchassis
Electronic Control System as Learning Device for Gasoline and Diesel Engine** – two separate
mobile trainer stands (Board A: Gasoline, Board B: Diesel), 1500 × 1800 × 600 mm each, with
lockable casters, lower cabinet (CPU, keyboard shelf, 12 V DC PSU) and colour-coded sensor sections.

## Features
- Switch Gasoline / Diesel / both boards
- Point-to-point measuring tool (mm) with vertex snapping and ΔX/ΔY/ΔZ
- Click any part to see its name, size and position
- Explode slider + animation, depth section cut, X-ray, wireframe, orthographic camera
- Standard views (iso, front, right, top, back, left), PNG screenshot
- Sensor list (S01–S30), parts list, downloads (2D/3D/exploded PDF, PNG, DWG)

Static site (Three.js from CDN) – no build step. Run locally with `python -m http.server`.
